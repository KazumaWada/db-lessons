# 1-1 SELECT・WHERE・ORDER BY・LIMIT(ウォームアップ)

読めば分かる SQL を、何も見ずに自分で書けるかどうかを試す回。
使うのは `products`(商品)と `users`(会員)だけ。

まず `./sql` で中に入って、次の2つを打ってテーブルの形を見てみよう。

```
\d products
\d users
```

(`\d` は SQL ではなく psql のコマンドなので、最後に `;` はいらない)

## 問題

答えは `answer.sql` の各 `-- Q` の下に書く。書けたら `./sql lessons/1-1/answer.sql` で実行して確かめる。

**Q1.** `products` の全部の列・全部の行を出す。

**Q2.** `products` の商品名(`name`)と値段(`price`)だけを出す。

**Q3.** 値段が 1000円以上の商品の、商品名と値段を出す。

**Q4.** 会員を「登録日(`created_at`)が新しい順」に並べて、名前と登録日を出す。

**Q5.** 値段が高い商品トップ3の、商品名と値段を出す。

**Q6.** 在庫(`stock`)が 0 の商品の名前を出す。

**Q7(書かずに考える問題).** Q5 で、もし3位と4位の商品が同じ値段だったら、結果はどうなると思う?
`answer.sql` にコメント(`-- `)で自分の考えを書いておいて。
