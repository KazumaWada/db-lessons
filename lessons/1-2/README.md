# 1-2 WHEREをくわしく(AND/OR・IN・BETWEEN・LIKE)

1-1 では条件が1つだけだった。今回は、条件を組み合わせたり、「〜のどれか」「〜から〜まで」「〜を含む」を書いたりする。
1-1 で出てきた「`name = 'A' AND 'B'` は書ける?」の疑問にも、ここで答えが出る。

使うのは `products`(商品)・`users`(会員)・`orders`(注文)。

## 問題

答えは `answer.sql` の各 `-- Q` の下に書く。書けたら `./sql lessons/1-2/answer.sql` で実行して確かめる。

**Q0(1-1 の持ち越し).** 値段が高い商品トップ3の、商品名と値段を出す。ただし、**値段が同じときは名前順**にする。
(ヒント: `order by` にはカンマで区切って複数の列を書ける)

**Q1.** 「モバイルバッテリー」と「ステンレスやかん」の2つの商品の、名前と値段を出す。`OR` を使って書く。

**Q2.** Q1 と同じ結果を、今度は `IN` を使って書く。

**Q3.** 東京都**以外**に住んでいる会員の、名前と都道府県を出す。

**Q4.** 値段が 1000円から3000円までの商品の、名前と値段を出す。`BETWEEN` を使って書く。
1000円ちょうど・3000円ちょうどの商品は入るのか、入らないのかも、コメントで書いておく。

**Q5.** 商品名に「ケーブル」が入っている商品の名前を出す。

**Q6.** 名前が「山」で始まる会員の名前を出す。

**Q7(予想してから実行する問題).** 「カテゴリが1(本)か4(ガジェット)で、値段が3000円以上」の商品を出したい。
ある人が次のように書いた。

```sql
select name, category_id, price from products
where category_id = 1 or category_id = 4 and price >= 3000;
```

実行する前に、何件出ると思うか、どの商品が出ると思うかをコメントに書く。
それから実行して、予想と違ったら、なぜそうなったのかを考える。最後に、正しく出る SQL を書く。

**Q8(書かずに考える問題).** 2025年5月1日から5月20日までの注文を出したくて、こう書いた。

```sql
select id, ordered_at from orders
where ordered_at between '2025-05-01' and '2025-05-20';
```

この SQL で、取りこぼしてしまう注文はあると思う? `answer.sql` にコメントで考えを書いておいて。
(書けたら実行して、`select id, ordered_at from orders order by ordered_at;` の結果と見比べてもいい)
