# 1-3 INSERT・UPDATE・DELETE

ここまでは「データを見る」だけだった。今回は、データを**追加する・書き換える・消す**。

見るだけの SELECT と違って、実行するとテーブルの中身が本当に変わる。
壊しても `./reset` で最初の状態に戻せるので、怖がらずに試してOK。

使うのは `products`(商品)と `users`(会員)。

## 問題

答えは `answer.sql` の各 `-- Q` の下に書く。書けたら `./sql lessons/1-3/answer.sql` で実行して確かめる。

**注意:** このファイルは実行するたびにデータが変わる(2回流すと、追加も2回される)。
もう一度最初から流したいときは、先に `./reset` してから実行する。

**Q1.** 新しい商品「ワイヤレスマウス」を追加する。
カテゴリは 4(ガジェット)、値段は 2980円、在庫は 30、登録日時は `2026-10-29 10:00:00`。
追加したら、`select` でちゃんと入ったか確かめる SQL も書く。

**Q2.** 新しい会員を **2人まとめて**(INSERT 1回で)追加する。

| 名前 | メール | 都道府県 | 誕生日 | 登録日時 |
|---|---|---|---|---|
| 森 陽介 | yosuke@example.com | 京都府 | 1990-04-01 | 2026-10-29 12:00:00 |
| 池田 りな | rina@example.com | 宮城県 | (わからない) | 2026-10-29 12:30:00 |

誕生日がわからない人は、どう書けばいいだろう?

**Q3.** 「SQLの絵本」の在庫が入荷して 20 になった。在庫を 20 に書き換える。

**Q4.** 文房具(カテゴリ 2)の商品を、全部 **10円値上げ** する。
(ヒント: 「今の値段 + 10」は `price + 10` と書ける)
書き換える前と後で、`select` して値段を見比べる。

**Q5.** Q1 で追加した「ワイヤレスマウス」を削除する。

**Q6(予想してから実行する問題).** 次の2つの商品を削除してみる。

- 「抹茶チョコレート」
- 「ボールペン 黒」

実行する前に、どちらも消せると思うか、予想をコメントに書く。
それから実行して、予想と違ったら、なぜそうなったのかを考える。
(ヒント: `\d products` の一番下に出てくる `Referenced by` を見てみよう)

**Q7(予想してから実行する問題).** Q2 で追加した「森 陽介」と同じメールアドレス `yosuke@example.com` で、別の人「森 太一」を追加しようとすると、どうなると思う?
予想を書いてから、実行してみる。

**Q8(書かずに考える問題).** ある人が「ステンレスやかん」だけを値下げしようとして、うっかりこう打ってしまった。

```sql
update products set price = 1000;
```

- 何が起きると思う?
- こういう事故を防ぐために、UPDATE や DELETE を打つ**前に**、どんなことをしておくといいと思う?

`answer.sql` にコメントで考えを書いておいて。(実行してみたくなったら、あとで `./reset` すれば戻せる)
